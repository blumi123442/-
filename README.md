# Последний рубеж — 2D браузерная игра на выживание

## Что нужно
- Node.js 18 или новее
- Интернет при первой установке зависимостей

## Запуск
1. Распакуй архив.
2. Открой терминал в папке `last_stand_survival`.
3. Выполни:
   ```bash
   npm install
   npm start
   ```
4. Открой в браузере `http://localhost:3000`.

## Мультиплеер
- На одном компьютере открой адрес в нескольких вкладках.
- Чтобы играть по локальной сети, узнай локальный IP компьютера с сервером и открой `http://IP-АДРЕС:3000` на других устройствах. Разреши Node.js входящие соединения в брандмауэре, если потребуется.
- Для игры через интернет сервер нужно разместить на хостинге/VPS и открыть порт 3000 или настроить `PORT`.

## Управление
- WASD или стрелки — движение
- Пробел / клик мышью — ударить зомби
- F — подобрать ближайший ресурс
- E — съесть еду
- B — построить баррикаду за 3 дерева

## Игровые механики
- Зомби преследуют ближайших игроков и наносят урон при контакте.
- Сытость постепенно снижается; при нуле начинает снижаться здоровье.
- Дерево и еда собираются рядом с персонажем.
- Состояние мира и игроки синхронизируются сервером через Socket.IO.

## Ограничения прототипа
Это минимальный игровой прототип: пока нет аккаунтов, постоянного сохранения, чата и защищённой системы возрождения. После смерти перезагрузи страницу, чтобы войти заново.
